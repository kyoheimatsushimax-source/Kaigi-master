# 即答会議ドリル

英語会議でよく使う26フレーズを練習するアプリです。会議の場面と日本語を見て、2秒以内に英語を声に出す練習をします。
オフラインで動くPWAで、iPhoneのホーム画面に追加して使えます。

## 機能
- **ドリル**
  - 場面と日本語を見て英語を声に出し、タップして答え合わせします。
  - 制限時間は2秒・3秒・5秒から選べます。
  - 答えを表示すると英語を読み上げます。
  - 自己採点は3段階です（即答できた／遅れた・崩れた／出なかった）。
  - 「即答できた」が続くと、次に出題されるまでの間隔が 1→3→7→14日 と伸びます。4段階目まで上がると「定着」と数えます。
  - 「出なかった」表現は、同じ回の中でもう一度出題されます。
- **マイ表現**
  - ★を付けた表現を中心に出題します。初期設定では次の6個に★が付いています。
    - The goal of today's meeting is to...
    - Just to clarify, are we talking about X or Y?
    - I'm not sure I agree, and here's why.
    - Let's park that for now.
    - Unless anyone objects, let's go with option B.
    - Let me check and get back to you by tomorrow.
  - 各表現に「自分の案件の言葉で書いた文」を登録できます。登録した文は、ドリルの答えにも表示され、読み上げられます。
  - 議長役で使う表現とメール用の表現にはタグが付いています。
- **次の会議で使う2つ**：ホーム画面で2つ選んでおき、会議の直前に見返します。
- **実戦ログ**
  - 会議の後に、実際に使えた表現をチェックします。
  - 直近の会議で3回連続使えた表現には「定着」と表示されます。定着した表現は★を外し、新しい表現と入れ替えてください。
- **一覧**
  - 全フレーズを一覧で表示し、タップで読み上げます。シャドーイング用です。
  - 読み上げ速度は「ゆっくり」「普通」から選べます。
- **バックアップ**：記録をJSONファイルに書き出したり、そのファイルから復元したりできます。

## ファイル構成
```
kaigi-drill/
├── index.html
├── manifest.json
├── sw.js
├── icon-192.png
├── icon-512.png
├── icon-maskable-512.png
├── apple-touch-icon.png   (iPhoneのホーム画面用)
├── favicon-32.png
├── .nojekyll
└── README.md
```

### アイコンを icons/ フォルダに入れず、直下に置いた理由
過去のアプリでは、GitHub Pagesに上げるとアイコンが反映されないことがありました。その対策として、次のようにしています。
- アイコンはすべてフォルダ直下に置き、相対パス（`./icon-192.png`）で参照しています。
  - `/icons/...` のように `/` で始まる絶対パスだと、`ユーザー名.github.io/` が基準になります。そのため、`/Eiken/` のようなリポジトリ配下に置くと、ファイルを見つけられません。
- `manifest.json` の `start_url` と `scope` は `./` にしています。
- `.nojekyll` を置き、GitHub Pagesの変換処理（Jekyll）を止めています。これで、ファイルがすべてそのまま配信されます。

## GitHub Pagesへの公開
1. リポジトリを作成します（例：`kaigi-drill`）。
2. ZIPを展開した中身を、リポジトリの直下にアップロードします。
   - フォルダごとではなく、中身をアップロードしてください。
   - `.nojekyll` は隠しファイルなので、見落とさないよう注意してください。
3. Settings → Pages → Branch: `main` / `(root)` を選んで Save します。
4. 数分後、`https://<ユーザー名>.github.io/kaigi-drill/` で開けるようになります。

## iPhoneのホーム画面に追加
1. Safariで上のURLを開きます。
2. 共有ボタン →「ホーム画面に追加」をタップします。

**注意：** 以前に同じURLを追加していた場合、iPhoneが古いアイコンを覚えていることがあります。その場合は、一度ホーム画面から削除してから、もう一度追加してください。

## 更新するとき
`sw.js` の `VERSION` を上げてからアップロードしてください（例：`v1.0.0` → `v1.0.1`）。
上げ忘れると、古い画面がキャッシュに残ることがあります。

## データの保存について
- 記録はブラウザの localStorage に保存されます。端末の外には送信されません。
- Safariで開いた場合と、ホーム画面に追加したアプリとでは、保存領域が別になることがあります。どちらか一方に決めて使ってください。
- 機種変更の前には「バックアップを保存」をしておいてください。
